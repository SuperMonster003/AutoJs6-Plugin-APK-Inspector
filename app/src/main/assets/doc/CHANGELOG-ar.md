# سجل الإصدارات

## v1.1.0

_2026/08/30_

- `تلميح` يتطلب بروتوكول Explorer Action v22 والوصول المحدود إلى ملف V4 إصدار AutoJs6 برمز 5277 أو أحدث
- `ميزة` أُضيف نسخ القيم الرئيسية في تفاصيل الحزمة بالضغط المطول ومشاركة التقرير النصي المطابق للشاشة عبر لوحة المشاركة في Android؛ يبقى المحتوى في الذاكرة ولا يطلب إذن التخزين أو ينشئ ملفًا
- `ميزة` إضافة نظرة عامة محدودة على DEX تسرد ملفات classes*.dex القياسية بترتيب طبيعي من أجزاء APK المختارة ووحدات AAB مع الحجم غير المضغوط لكل ملف والإجمالي، مع مشاركة مرور الدليل المركزي للمكتبات الأصلية من دون استخراج محتوى DEX أو فك ترميزه أو تفكيكه
- `ميزة` أضيفت نظرة عامة محدودة على المكتبات الأصلية تجمع ملفات .so من أجزاء APK المختارة ووحدات AAB حسب ABI والحجم غير المضغوط، مع وسم ABI المفضل والبدائل المتوافقة وغير المدعومة من دون استخراج المحتوى
- `ميزة` أضيفت إحصاءات محدودة لمكونات manifest تشمل activity/الأسماء المستعارة وservice وbroadcast receiver وcontent provider عبر أجزاء APK المختارة ووحدات AAB المفحوصة، مجمعة حسب حالة android:exported الصريحة مع وسم النتائج الجزئية
- `ميزة` أضيف التحقق التشفيري على الجهاز لنظم APK ‏V2 وV3 وV3.1 وV4 وV4.1، بما يشمل ملخصات المحتوى وإثباتات الموقّع وجذور fs-verity وأشجار Merkle المضمنة ومطابقة نظام التوقيع المكمل
- `ميزة` أضيفت حقول الشهادات التفصيلية وسلاسل التدوير المتحقق منها مع أدوار القديم/الحالي وأعلام القدرات وبصمات SHA-256
- `ميزة` أضيف نسخ `.idsig` المحدود عبر واصف مطابق للقراءة فقط يشتقه المضيف؛ ولا يتاح تعداد المجلدات أو الوصول العشوائي إلى الملفات المجاورة
- `ميزة` أضيف تجميع الأذونات المطلوبة حسب `protectionLevel` إلى وقت التشغيل/خطرة والتوقيع/محمية وعادية؛ مع إبراز أذونات وقت التشغيل أولًا وإرفاق شرح موجز محدود، فيما تظل المستويات غير المتاحة ظاهرة وموسومة
- `تحسين` عُزز تدقيق طلبات Explorer Action v22 واللقطات الخاصة غير القابلة للتغيير، مع حد 4 GiB للحزمة و40 MiB لـ idsig وفحوص الهوية والإغلاق السريع لجلسة المضيف
- `تحسين` أضيفت مصفوفة عينات رسمية مولدة بأداة Build Tools 37 `apksigner` للتوقيعات الصحيحة والمعدلة ومتعددة الموقّعين وتدوير V3.1/V4.1 والحالات المفقودة والتالفة

## v1.0.0

_2026/08/02_

- `تلميح` أول إصدار علني؛ يتطلب AutoJs6 برمز إصدار 5269 أو أحدث
- `ميزة` انقر على ملف APK أو APKS أو XAPK أو APKM أو APKZ أو AAB في مدير ملفات AutoJs6 لفتح تقرير فحص للقراءة فقط (معرف الإضافة `apk-inspector`، ومعرف الإجراء `inspect-android-package`)
- `ميزة` يعرض التقرير اسم التطبيق وأيقونته، واسم الحزمة، والإصدار، ونطاق SDK، والأذونات المطلوبة، والأجزاء المقسمة وموارد OBB، والمشكلات البنيوية، ووجود أنظمة التوقيع V1-V3
- `ميزة` تُفك تلقائيًا ملفات manifest النصية والثنائية في APK، وملفات protobuf في AAB، وبيانات bundletool الوصفية `toc.pb`، مع عارض مستقل لملف manifest المنسق
- `ميزة` يمكن للتطبيقات الأخرى تمرير حزمة عبر «فتح باستخدام» (ACTION_VIEW) باستخدام أنواع MIME المخصصة لحزم Android
- `ميزة` قبل الفحص يُنسخ الملف إلى لقطة خاصة للقراءة فقط مع حساب SHA-256 (بحد أقصى 4 GiB)؛ ولا تطلب الإضافة أذونات التخزين أو الشبكة أو التثبيت
- `ميزة` تتوفر بعشر لغات لواجهة الاستخدام والتعليمات وREADME وCHANGELOG: الصينية المبسطة، والصينية التقليدية (هونغ كونغ وتايوان)، والإنجليزية، والفرنسية، والإسبانية، واليابانية، والكورية، والروسية، والعربية
- `تبعية` إضافة Gson 2.13.2
