# История версий

## v1.1.0

_2026/08/30_

- `Подсказка` Требуется AutoJs6 с кодом версии 5277 или новее для протокола Explorer Action v22 и ограниченного доступа к файлу V4
- `Функция` Добавлено копирование основных значений сведений о пакете долгим нажатием и отправка точного текстового отчёта через системное меню Android; содержимое остаётся в памяти, не требует разрешения на хранилище и не создаёт файл
- `Функция` Добавлен ограниченный обзор DEX: стандартные файлы classes*.dex выбранных split-APK и модулей AAB перечисляются в естественном порядке с размером без сжатия для каждого файла и в сумме; используется общий проход центрального каталога с нативными библиотеками без извлечения, декодирования или декомпиляции содержимого DEX
- `Функция` Добавлен ограниченный обзор нативных библиотек: файлы .so выбранных split-APK и модулей AAB сгруппированы по ABI и размеру без сжатия, с отметками предпочтительных, резервно совместимых и неподдерживаемых ABI без извлечения содержимого
- `Функция` Добавлена ограниченная статистика компонентов манифеста для activity/псевдонимов, service, broadcast receiver и content provider в выбранных split-APK и просканированных модулях AAB, сгруппированная по явному состоянию android:exported с пометкой частичных результатов
- `Функция` Добавлена криптографическая проверка на устройстве схем APK V2, V3, V3.1, V4 и V4.1, включая дайджесты содержимого, доказательства подписанта, корни fs-verity, встроенные деревья Меркла и сопоставление с дополнительной схемой
- `Функция` Добавлены подробные поля сертификатов и проверенные цепочки ротации с прежними/текущими ролями, флагами возможностей и отпечатками SHA-256
- `Функция` Добавлено ограниченное копирование `.idsig` через точный дескриптор только для чтения от хоста; перечисление каталогов и произвольный доступ к соседним файлам недоступны
- `Функция` Запрошенные разрешения сгруппированы по `protectionLevel` на разрешения времени выполнения/опасные, подписи/защищённые и обычные; опасные показаны первыми с ограниченным пояснением в одну строку, а недоступные уровни остаются видимыми и помечаются
- `Улучшение` Усилены проверка запросов Explorer Action v22 и неизменяемые закрытые снимки: пределы 4 GiB для пакета и 40 MiB для idsig, проверки идентичности и быстрое закрытие сеанса хоста
- `Улучшение` Добавлена официальная матрица образцов Build Tools 37 `apksigner`: действительные, изменённые, с несколькими подписантами, ротацией V3.1/V4.1, отсутствующие и повреждённые подписи

## v1.0.1

_2026/08/08_

- `Исправление` Исправлена невозможность привязки хоста к службе плагина после его включения в центре плагинов; действие «Проверить пакет Android» теперь работает сразу после включения
- `Улучшение` Упрощены название и описание плагина, пользовательская документация стала читаться естественнее

## v1.0.0

_2026/08/02_

- `Подсказка` Первый публичный выпуск; требуется AutoJs6 с кодом версии 5269 или новее
- `Функция` Коснитесь файла APK, APKS, XAPK, APKM, APKZ или AAB в файловом менеджере AutoJs6, чтобы открыть отчёт проверки в режиме только чтения (ID плагина `apk-inspector`, ID действия `inspect-android-package`)
- `Функция` Отчёт показывает имя и значок приложения, имя пакета, версию, диапазон SDK, запрошенные разрешения, split-файлы и OBB-ресурсы, структурные проблемы и наличие схем подписи V1-V3
- `Функция` Текстовые и двоичные манифесты APK, protobuf-манифесты AAB и метаданные bundletool `toc.pb` декодируются автоматически; для отформатированного манифеста предусмотрен отдельный просмотрщик
- `Функция` Другие приложения могут передать пакет через системное «Открыть с помощью» (ACTION_VIEW) с выделенными MIME-типами пакетов Android
- `Функция` Перед проверкой файл копируется в закрытый снимок только для чтения с вычислением SHA-256 (лимит 4 GiB); плагин не запрашивает разрешений на хранилище, сеть или установку
- `Функция` Поставляется на 10 языках: интерфейс, инструкции, README и CHANGELOG — упрощённый китайский, традиционный китайский (Гонконг и Тайвань), английский, французский, испанский, японский, корейский, русский и арабский
- `Зависимость` Добавлен Gson 2.13.2
