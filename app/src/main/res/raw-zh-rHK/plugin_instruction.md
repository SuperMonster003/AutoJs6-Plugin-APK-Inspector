# APK 檢查器

APK 檢查器在檔案管理器中為 APK, APKS, XAPK, APKM, APKZ 和 AAB 檔案提供主要唯讀檢查動作.

它顯示套件詳情, 要求權限, 元件, 裝置配對分割, OBB 資源, 結構發現, APK V1-V3 簽章配置存在性和格式化 Android 資訊清單.

插件要求主程式組建版本 5277+.

安全和私隱限制:

- 透過臨時唯讀 `content` URI 存取開啟來源檔案.
- 輸入僅複製一次到私人唯讀快照, 上限為 4 GiB, 同時計算 SHA-256.
- 外掛程式不要求儲存空間, 網絡或套件安裝權限.
- 外掛程式不會安裝或修改套件. 簽章配置僅檢查存在性.
