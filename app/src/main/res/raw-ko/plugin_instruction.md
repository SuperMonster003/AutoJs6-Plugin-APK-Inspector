# APK Inspector

APK Inspector는 파일 관리자에서 APK, APKS, XAPK, APKM, APKZ, AAB 파일을 위한 기본 읽기 전용 검사 동작을 제공합니다.

패키지 세부 정보, 요청 권한, 구성 요소, 기기에 맞는 분할 APK, OBB 자산, 구조 결과, APK V1-V3 서명 방식 존재 여부, 정리된 Android Manifest를 표시합니다.

플러그인에는 호스트 빌드 5269 이상이 필요합니다.

안전 및 개인정보 제한:

- 소스는 임시 읽기 전용 `content` URI 접근으로 열립니다.
- 입력은 SHA-256을 계산하며 4 GiB로 제한된 비공개 읽기 전용 스냅샷으로 한 번 복사됩니다.
- 저장소, 네트워크, 패키지 설치 권한을 요청하지 않습니다.
- 패키지를 설치하거나 수정하지 않습니다. 서명 방식은 존재 여부만 확인합니다.
