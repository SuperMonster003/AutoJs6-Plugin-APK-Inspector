# APK Inspector

APK Inspector предоставляет основное действие проверки только для чтения в файловом менеджере для файлов APK, APKS, XAPK, APKM, APKZ и AAB.

Он показывает сведения о пакете, запрошенные разрешения, компоненты, подходящие устройству split APK, ресурсы OBB, структурные находки, наличие подписей APK V1-V3 и форматированный Android manifest.

Плагину требуется сборка хоста 5269 или новее.

Ограничения безопасности и конфиденциальности:

- Исходный файл открывается через временный URI `content` только для чтения.
- Входные данные один раз копируются в приватный снимок только для чтения с лимитом 4 GiB и вычислением SHA-256.
- Плагин не запрашивает разрешения хранилища, сети или установки пакетов.
- Плагин не устанавливает и не изменяет пакеты. Схемы подписи проверяются только на наличие.
