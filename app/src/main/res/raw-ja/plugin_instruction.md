APK Inspector は APK, APKS, XAPK, APKM, APKZ, AAB パッケージをインストール前に検査し, アプリ名, バージョン, 権限, コンポーネント, 署名などを表示して, この端末にインストールできるかを判定します. 検査は読み取りのみで, パッケージをインストールすることも元のファイルを変更することもありません.

### はじめに

1. AutoJs6 の "プラグインセンター" で本プラグインが有効になっていることを確認します.
2. AutoJs6 のファイルマネージャーを開き, 検査するパッケージファイルを探します.
3. ファイルをタップするか, メニューから "Androidパッケージを検査" を選びます (AutoJs6 6.8.1 以降では最上位メニュー "APK Inspector" の中にあります).
4. レポートの "パッケージ詳細", "コンポーネント", "要求権限", "セキュリティと互換性の結果" を上から順に確認します.

### 主な機能

- **パッケージ詳細**: パッケージ名, バージョン, 最小 SDK とターゲット SDK をこの端末と照らし合わせて表示します. 項目を長押しすると値をコピーできます.
- **署名の検証**: V2, V3 などの署名方式を検証し, 署名証明書のフィンガープリントを表示します.
- **要求権限**: 権限を実行時, 署名, 通常の 3 グループに分けて表示し, 実行時権限を先頭に短い説明付きで示します.
- **コンポーネント**: activity, service, receiver, provider をまとめ, それぞれがエクスポートされているかを示します.
- **セキュリティと互換性の結果**: ベース APK の欠落, 分割 APK の重複, バージョンやパッケージ名の不一致などの問題を指摘し, ブロッキングな問題とヒントを区別します.
- **端末構成シミュレーション**: APKS などのセットで言語, 画面密度, ABI を切り替え, "シミュレーション構成を適用" をタップすると, 選ばれた分割 APK をこの端末と比較できます.
- **manifestを表示**: AndroidManifest を行番号と構文ハイライト付きの XML で表示し, "マニフェスト内を検索" でテキストを検索できます.
- **レポートを共有**: 画面と同じ内容のテキストレポートをシステムの共有メニューで送信します. ファイルは作成しません.

### 動作要件

- Android 7.0 以降.
- AutoJs6 6.8.0 以降.
- ストレージ, ネットワーク, インストールの権限は不要です. プラグインはファイルマネージャーで選んだファイルだけを読み取ります.

### よくある質問

**パッケージをインストールしない理由**

このプラグインはインストール前にパッケージの中身を確認するためのものなので, インストール権限を要求せず, インストールボタンもありません. インストールにはシステムのインストーラーか AutoJs6 自身のインストール手順を使ってください.

**一部のファイルを検査できない理由**

よくある原因は, 8 GiB を超えるファイル, 空きキャッシュ領域が 128 MiB 未満, 読み取り中に他のアプリがファイルを変更した, ファイル自体が壊れている, などです. レポート画面のエラーメッセージに原因が表示されます.

**有効な署名の意味**

有効な署名は, 署名後にファイルが変更されていないことを示すだけで, 署名者やアプリが信頼できることの証明にはなりません. 証明書のフィンガープリントや SHA-256 を公式の配布元が公開している値と照合してください.

**AAB ファイルを直接インストールできない理由**

AAB はアプリストア向けの配布形式で, Android 端末に直接インストールすることはできません. プラグインは manifest とモジュール構成を表示できます. インストールする前に bundletool などのツールで APK か APKS に変換してください.

詳しくは [プロジェクトページ](https://github.com/SuperMonster003/AutoJs6-Plugin-APK-Inspector) をご覧ください.
