# APK 檢查器

APK 檢查器在檔案管理器中為 APK, APKS, XAPK, APKM, APKZ 和 AAB 檔案提供主要唯讀檢查動作.

它顯示套件詳細資料, 要求權限, 元件, 裝置相符分割, OBB 資源, 結構發現, APK V1-V3 簽章配置存在性和格式化 Android 資訊清單.

外掛要求主程式建置版本 5269+.

安全與隱私限制:

- 透過暫時唯讀 `content` URI 存取開啟來源檔案.
- 輸入只複製一次到私人唯讀快照, 上限為 4 GiB, 同時計算 SHA-256.
- 外掛不要求儲存空間, 網路或套件安裝權限.
- 外掛不會安裝或修改套件. 簽章配置只檢查存在性.
